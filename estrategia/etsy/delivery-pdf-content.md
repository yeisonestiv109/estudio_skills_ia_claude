## 💡 Quick Tips

**Occupancy formula:** the system uses 90 nights as the available period. To change it, edit the `90` in the Dashboard Occupancy column formula to your actual available nights (e.g., 365 for annual tracking).

**Multiple properties:** names "Property 1" through "Property 5" can be renamed in the Setup tab. Update the dropdowns in Bookings and Expenses if you change them.

**More than 98 bookings/expenses?** Copy the last formatted row and paste it downward — formulas will extend automatically.

**Full user guide:** a complete step-by-step guide is included in the User Guide PDF (separate file in your download).

## INSTRUCCIONES PARA DISEÑAR EN CANVA

1. Crear un diseño de **2 páginas, tamaño A4** (210×297mm).
2. **Página 1:** fondo oscuro `#1E1F28`, texto blanco. Header con ícono/logo de tienda. Links en azul `#34A0DB` subrayado.
3. **Página 2:** fondo blanco o gris claro `#F4F5F7`, texto oscuro. Cuadro de disclaimer con borde ámbar `#F1C40F`.
4. Tipografía: **Inter** o Montserrat (la más parecida en Canva a Inter).
5. Antes de publicar en Etsy: reemplazar `[PASTE YOUR GOOGLE SHEETS LINK HERE]` con el link real de "Anyone with the link can view".
6. Exportar como **PDF (standard)** y subir como file al listing de Etsy.
