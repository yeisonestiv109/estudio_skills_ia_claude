# Reglas del Juego (no negociables)

Reglas operativas para empezar hoy. Pocas, claras y verificables. **Si una decisión viola una de estas reglas, no se ejecuta.**

## Dinero y disciplina

- **Fondo de emergencia primero.** Antes de reinvertir agresivo, asegurar 3–6 meses de gastos. Reinvertir solo el excedente (corrige la versión peligrosa de "Stay Broke").
- **Regla del 20%.** Cada lunes defino las 2–3 tareas que mueven ingresos o aprendizaje real. Esas van primero; el resto se delega, automatiza o elimina.
- **Medir el dinero por unidad.** En todo servicio/producto conozco mi costo por entrega y mi margen. En Glovar: costo por lead calificado vigilado siempre.

## Ventas y posicionamiento

- **Vender resultados, no tareas.** Toda propuesta se redacta como resultado de negocio y se conecta a una de las 3 reglas de oro (ganar dinero / ahorrar tiempo / ahorrar dinero).
- **ICP por escrito antes de cada campaña** de prospección. Sin ICP no se prospecta.
- **Medir el embudo desde el día 1:** contactos → respuestas → reuniones → cierres.
- **Verificar que el cliente puede absorber el resultado** (área de delivery) antes de cerrar.

## IA y desarrollo

- **La IA es vehículo, no producto.** Se usa para ir más rápido/barato/escalable, no como fin.
- **IA crítica, no complaciente.** Le pido contras, riesgos y que cuestione supuestos. No la uso para decisiones personales/emocionales.
- **Validar datos con fuentes** (fuente + fecha) antes de convertir algo en estrategia.
- **Stack orquestado por fase:** Kiro → Claude Code → Antigravity → Claude Code (CI/CD).

## Legal y reputación

- **Cumplir Habeas Data (Ley 1581/2012).** Preferir datos corporativos; documentar base legal.
- **Cold email responsable:** identificación, motivo, opción de baja, dominio con SPF/DKIM/DMARC.
- **Respetar ToS** de LinkedIn/Google/APIs; tener fuentes alternativas ante bloqueos.

## Cadencia

- **Revisión semanal (viernes):** ¿qué generó ingresos/aprendizaje? ¿qué fue ruido? Ajustar el plan de la semana siguiente.
